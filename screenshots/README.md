# Скриншоттарды жинау нұсқаулығы

Бұл бумада талап етілетін төрт дәлел материалының SVG нұсқалары бар. Олар GitHub-та алдын ала қаралады және қандай нәтиже көрсетілуі керегін көрсетеді. Тапсыру алдында қосымшаны `dotnet run` арқылы іске қосып, браузерден нақты PNG/JPG скриншоттарын түсіріп, осы файлдармен ауыстырыңыз.

## Қажетті төрт скриншот

1. `01-register.png` — тіркелу формасы және сәтті тіркелу нәтижесі.
2. `02-login.png` — кіру формасы және жүйеге кірген пайдаланушы.
3. `03-student-restriction.png` — Student аккаунты: тізім көрінеді, Delete батырмасы жоқ немесе Admin әрекетіне Access Denied көрсетіледі.
4. `04-admin-access.png` — Admin аккаунты: тізім көрінеді және Delete батырмасы бар.

## Түсіру тәртібі

1. `dotnet ef database update` және `dotnet run` командаларын орындаңыз.
2. Тіркелу бетін ашып, скриншот түсіріңіз.
3. Жаңа Student аккаунтымен кіріп, `/Students` бетін түсіріңіз.
4. README-дегі нұсқаулықпен сол пайдаланушыға Admin рөлін беріңіз.
5. Шығып, қайта кіріп, Delete батырмасы бар `/Students` бетін түсіріңіз.
6. Файлдарды осы бумаға PNG форматында сақтаңыз.

SVG файлдары нақты браузер экраны емес, скриншотта көрсетілетін нәтижені алдын ала көрсететін нұсқа. Нақты суреттерді қосқаннан кейін оларды `01-register.png`, `02-login.png`, `03-student-restriction.png`, `04-admin-access.png` деп атаңыз.
